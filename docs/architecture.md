# Arquitetura — Telefoninho

Esta documentação inicial descreve o objetivo do monorepo e os pontos de integração.

- API (`services/api`): gerencia famílias, membros, regras e provisioning.
- Painel (`apps/parent-web`): edição e operação por responsável.
- Android (`apps/child-android`): app simples para criança.
- Asterisk (`infra/asterisk`): backend VoIP e controle de chamadas.

Ainda em fase inicial (bootstrap), sem fluxos completos implementados.
