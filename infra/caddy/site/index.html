Painel da família

Um telefone
para conversar.

O Telefoninho é um telefone infantil com contatos escolhidos pela família. A criança liga. Quem cuida organiza.

Como funciona Conhecer a ideia física

A conversa começa por aqui.

  1. 01

    Família escolhe
    os contatos.

    No painel, os responsáveis organizam os contatos e definem quem pode ligar para quem.

  2. 02

    Criança usa
    o Telefoninho.

    Hoje, o Telefoninho é um app Android. A família conecta o aparelho por um código, e a criança usa uma agenda simples para ligar.

  3. 03

    A ligação acontece
    pela internet.

    As chamadas são de voz, com os contatos autorizados. Os aparelhos precisam estar conectados à internet para conversar.

MAIS LONGE

E se o telefoninho
não tivesse tela?

Uma possibilidade é levar a mesma ideia para um aparelho físico: botões para os contatos, microfone, alto-falante e Wi-Fi. Pegar o fone, escolher uma pessoa, conversar.

A família continuaria organizando os contatos pelo painel. A criança usaria o telefone sem precisar de uma tela.

Possibilidade em estudo. O projeto hoje funciona como app Android.
